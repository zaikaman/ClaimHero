## 3. Technology Stack & Architectural Pillars

The hackathon is anchored around an integrated stack designed for autonomous, full-stack applications:

1. **Backend Engine (Convex):**
   - Must serve as the core persistence and compute layer.
   - Utilizes reactive queries, ACID transactions, mutations, background actions, scheduling / crons, file storage, full-text / vector indexing, and HTTP routing.
   - Hosting target: Convex static hosting (`convex.site`).

2. **Data Ingestion & Intelligence (Firecrawl):**
   - Used for live data extraction, web crawling, scraping unstructured web sources, and feeding clean structured data into Convex.

3. **Autonomous Communications & Inboxes (AgentMail):**
   - Provides dedicated programmatic email inboxes for agents.
   - Handles two-way external email exchanges, payer/service transmission, and inbound webhook processing.

4. **Agentic Coding & Intelligence (OpenAI / Codex / Agent Ecosystem):**
   - Participants build using AI coding agents (such as Codex, Antigravity IDE, Claude, or ChatGPT) augmented with Convex agent plugins.
   - Integrates OpenAI models for reasoning, multimodal extraction, and structured synthesis.

## 5. Submission Requirements & Checklist

Every valid project submission on [vibeapps.dev](https://vibeapps.dev) must include:

1. **Public GitHub Repository:**
   - Contains clean, complete source code.
   - Free of mock, stubbed, or hardcoded mock data. Everything must be functional and production-grade.

2. **`hackathon.md` Build Log at Repository Root:**
   - A chronological, evidence-based build log detailing project architecture, components, commits, timestamps (UTC), and milestone progress.
   - Maintained throughout development using the `/hackathon` agent command.
   - Serves as the primary written reference for the judging committee.

3. **Publicly Accessible Live URL:**
   - Deployed and reachable on a `convex.site` or `chatgpt.site` domain.
   - Must allow instant public evaluation without requiring private access requests or gated invites.

4. **3-Minute Demo Video:**
   - Maximum length of 3 minutes.
   - Walks through real user workflows, live feature demonstrations, architectural integration, and real-world impact.

---

## 6. Evaluation & Judging Criteria

Judges evaluate submissions across the following core dimensions:

1. **Real-World Utility:**
   - Focus on practical applications that solve tangible problems for human end-users or businesses, rather than purely meta developer utilities.

2. **Full-Stack Integration Depth:**
   - Meaningful, tight integration of the four pillars: Convex reactivity, Firecrawl data ingestion, AgentMail communications, and AI reasoning.

3. **Technical Rigor & Polish:**
   - End-to-end functionality, high reliability, robust schema design, zero fake fallbacks, and polished UI/UX interaction.

4. **Transparency & Process (`hackathon.md`):**
   - Quality of documentation, architectural clarity, and truthful representation of what was built and verified during the build window.
